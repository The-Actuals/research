# The Actuals: research data

The real numbers behind small online businesses: what they charge, earn, pay in fees and sell for. Every study we publish has its full dataset, sources and method here, so you can check each number or rerun it yourself.

## How we work

We collect public data ourselves (pricing pages, marketplace listings, government surveys, public posts), count it, and publish both the data and the code. When a number is self-reported, or a list price rather than a sale price, the study says so next to it. Where we analyzed public Reddit or Hacker News posts, we publish links and our own coded fields only, never the posts' text.
